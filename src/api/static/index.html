Adaptive LLM Router

Most questions don't need the most expensive model. This router decides, per question, whether a cheap model is enough, and escalates to the large one when the cheap answer fails quality checks.

The code question was answered by the small model before the router learned the asks_for_code feature. It now routes that question to the large model, and the small model's answer above shows that was a cautious choice, not a necessary one.

How it works

  1. Read the question. Seven cheap, readable signals: reasoning words, simple-task words, whether it asks for or contains code, length, and listed constraints. No embeddings: an embedding call would cost as much as the routing saves.
  2. Decide. A logistic regression turns those signals into a probability. At 0.50 or above, the question goes to the large model. It agrees with hand labels 78% of the time (mean of 20 repeated 5-fold splits), against 55% for always guessing the common answer.
  3. Check the cheap answer. Deterministic checks, not a second AI call: empty, refused, cut off, hedging, or missing code that was asked for.
  4. Escalate if needed. A failed check retries once on the large model, so a wrong routing guess costs one extra call, not a wrong answer.
